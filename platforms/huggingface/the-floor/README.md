## What it is

The floor is the ground an AI can be built on, in the words of The 420 Code: every line it rests on, with the kill switch that would end it. It comes in three forms, generated from one source: the short form an agent reads (`floor.txt`), the structured file (`floor.json`, with its schema), and the page (`page.html`).

Anyone can check that a copy is unaltered: compute the SHA-256 of `floor.txt` and compare it with the fingerprint above, and with the one at home.
