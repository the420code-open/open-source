# Safety findings, and what is never hosted

**A finding that could do harm if it were public,** a flaw or a dangerous use, is reported privately, never in an open issue. Use GitHub's private reporting for this repository, or write to open@studiog.global with "Safety" as the subject. The record shows that a report was received, and a safe summary once it is dealt with.

**Hosted here:** specifications, tests, results, run packets, and small reference code.

**Never hosted here:** trained model weights, agents that act on the internet, programs to run, personal data, and any data about the people in a study.

**Never run here:** code sent in. Nothing sent in runs on this repository's machines. Where a result is run again, it is run in a sealed workspace, with no keys and no network.
