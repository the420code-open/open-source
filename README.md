# The 420 Code · Open Source

The 420 Code starts from one line: one record exists. Try to deny it, and the denial is another record.

Every claim in the work says how it could be wrong. Each one carries a kill switch: the written condition under which that claim dies. The switches are listed in one registry, the Master Kill Switch Registry, at the420code.org.

This is where the work is opened up. To be tested. To be attacked. To be built on.

**What is here.** The Embryo. It is not an AI. It is the floor an AI can be built on, in three layers: the floor itself; the tests that show whether an AI stands on that floor, or only quotes it; and a simulated world, built on the work's own conditions. And the open record of everything sent in.

**How to take part.** Go to the Open Source room, on the family's sites, and choose Send your work. A first try takes a minute. If you already work on GitHub, the forms under Issues do the same.

**The terms.** Everything built here is free. Use it, change it, share it, for anything, without asking. The 420 Code itself is free to share, and never altered. NOTICE.md says which is which.
